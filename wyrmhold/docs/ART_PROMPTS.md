# Wyrmhold — AI Art Prompts

Use these in any image generator (ChatGPT/DALL·E, Gemini, Midjourney, etc.).
Every prompt ends with the shared **style line** so the whole game looks like
one set. Save each image with the **filename** shown and send them to Claude;
they drop into `public/art/` and replace the drawn SVG scenes automatically.

**Style line (append to every prompt):**
> painterly dark fantasy illustration, muted sea-slate blues and ember orange
> accents, dramatic rim lighting, cinematic, high detail, no text, no
> watermark, portrait orientation 3:4

**Size:** 768×1024 (portrait) for scenes and characters.
